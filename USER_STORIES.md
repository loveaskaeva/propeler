# User Stories и описание проекта Propeler

## Описание проекта
Propeler — это современный лендинг + REST API для демонстрации инновационных решений в сфере веб-разработки и приёма заявок от клиентов. Сайт ориентирован на привлечение новых клиентов и демонстрацию портфолио команды.

## Целевая аудитория
- Владельцы малого и среднего бизнеса.
- Стартапы, ищущие быстрые и качественные веб-решения.
- HR-специалисты, оценивающие навыки команды.

## User Stories

### 1. Как потенциальный клиент...
**Я хочу** видеть четкий список услуг и возможностей команды на главной странице,
**Чтобы** быстро понять, подходит ли этот проект для решения моих задач.

### 2. Как пользователь...
**Я хочу**, чтобы сайт корректно отображался на моем мобильном телефоне,
**Чтобы** я мог изучить информацию в любое удобное время в пути.

### 3. Как администратор...
**Я хочу**, чтобы проект имел чистую структуру кода и документацию,
**Чтобы** я мог легко вносить изменения и расширять функционал сайта.

### 4. Как посетитель...
**Я хочу** видеть информацию об авторских правах и контакты внизу страницы (футер),
**Чтобы** убедиться в легитимности проекта и знать, как связаться с командой.

## Описание моделей данных

### Сущность `Service` (Услуга)
Таблица: `services`

| Поле          | Тип SQL     | Описание                                           | Ограничения / валидация                       |
|---------------|-------------|----------------------------------------------------|-----------------------------------------------|
| `id`          | INTEGER     | Первичный ключ                                     | PRIMARY KEY, INDEX                            |
| `name`        | VARCHAR(150)| Название услуги (например, «Разработка лендинга») | NOT NULL, длина 2–150 символов, INDEX        |
| `description` | TEXT        | Подробное описание                                 | NULLable                                      |
| `price`       | NUMERIC(10,2)| Стоимость услуги                                 | NOT NULL, `price >= 0`                        |
| `is_active`   | BOOLEAN     | Флаг «услуга активна и отображается в списке»     | NOT NULL, DEFAULT TRUE                        |
| `created_at`  | DATETIME    | Дата и время создания записи                      | NOT NULL, DEFAULT `utcnow()`                  |

**Связи:** одна услуга → много заявок `ContactRequest`.

---

### Сущность `ContactRequest` (Заявка клиента)
Таблица: `contact_requests`

| Поле          | Тип SQL     | Описание                                           | Ограничения / валидация                       |
|---------------|-------------|----------------------------------------------------|-----------------------------------------------|
| `id`          | INTEGER     | Первичный ключ                                     | PRIMARY KEY, INDEX                            |
| `client_name` | VARCHAR(150)| Имя клиента                                        | NOT NULL, длина 2–150 символов               |
| `email`       | VARCHAR(200)| Email клиента                                      | NOT NULL, валидация формата email, INDEX      |
| `phone`       | VARCHAR(30) | Телефон клиента                                    | NULLable, до 30 символов                      |
| `message`     | TEXT        | Сообщение / комментарий                            | NULLable                                      |
| `service_id`  | INTEGER     | FK → `services.id` (какая услуга интересна)        | NULLable, Foreign Key, `ON DELETE SET NULL`   |
| `created_at`  | DATETIME    | Дата и время заявки                                | NOT NULL, DEFAULT `utcnow()`                  |

**Связи:** много заявок → одна услуга (`service_id` → `services.id`).
